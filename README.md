# Linear Sprint Status

Reads Linear before the team wakes up and posts what's shipping, what's blocked, and what's at risk this cycle. @mention it any time for a follow-up.

## Prerequisites
- A [Linear](https://linear.app) workspace where you can authorize the Linear MCP via OAuth
- A Slack workspace where you can install the agent's bot and invite it to one or more channels
